# Agentic Hub

The open registry of **skills** and **agent packages** for Agentic. Use them on Agentic in one click, or install them on your own machine.

Everything here is open source, reviewed by the Agentic team, and checked automatically for leaked keys, hidden text and risky scripts.

## What's inside

| Folder | What it is | Works with |
|---|---|---|
| `skills/<name>/` | A skill: a `SKILL.md` that teaches an agent one task, plus optional scripts and references. Standard [Agent Skills](https://agentskills.io) format. | Claude, OpenClaw, Hermes Agent: each skill lists the engines it was tested on. |
| `agents/<name>/` | An agent package: an engine, a personality, instructions (`AGENTS.md`) and a list of skills from this registry. | The one engine it declares in `runtime`. |
| `index.json` | Everything above in one file, generated by `npm run index`. Agentic reads it. | |

An **engine** (Claude Code, OpenClaw, Hermes Agent) is the program that runs an agent. A **skill** is know-how any engine can load. An **agent package** is a ready-made setup for one engine.

## Install a skill on your machine

```bash
git clone --depth 1 https://github.com/Agentic-agenthub/agentic-hub
```

Then copy the skill's folder where your engine looks for skills:

| Engine | Folder |
|---|---|
| Claude Code | `~/.claude/skills/` |
| OpenClaw | `~/.openclaw/skills/` |
| Hermes Agent | `~/.hermes/skills/` |

```bash
cp -r agentic-hub/skills/inbox-zero ~/.claude/skills/
```

Read a skill's files before you install it, scripts especially.
